# Изменения

## 0.2.0 — 28.10.2026

- Добавлено Android-приложение с CameraX, предпросмотром и отправкой фотографии другу.
- Добавлены демопрофили Аня и Максим, сохранение настроек и проверка соединения с сервером.
- Реализована нормализация EXIF-ориентации перед отправкой JPEG.
- Добавлен виджет с последним входящим мемом, ручным обновлением и дисковым кэшем.
- Добавлены состояния загрузки, отсутствия фотографий и ошибок сети.
- Разработаны оформление приложения и адаптируемый интерфейс виджета.
- Добавлены автоматические проверки Android, сквозной тест API и рендеры интерфейса.
- Обновлены пользовательское руководство, инструкции сервера, сборки и тестирования.

## 0.1.0

- Реализован backend: два демопользователя, приём фотографий, квадратная обрезка, случайные надписи и фильтры.
- Добавлены API последней входящей фотографии и скачивания готового JPEG.
