# Дизайн Memit

Интерфейс использует палитру логотипа `logo.PNG`: жёлтый `#FFC434`, фиолетовый `#514382`, светлый фон `#FAF7F0`, основной текст `#30294F`. Значок приложения — векторная M на фиолетовой подложке.

## Экран камеры

В верхней части расположены логотип и настройки. Заголовок «Твой кадр. Его новый мем.» сопровождается выбранным направлением отправки. Камера и предпросмотр находятся в скруглённой карточке. После съёмки доступны кнопки «Переснять» и «Отправить».

Экран прокручивается на небольших устройствах, учитывает системные панели и вырезы. Изменения статуса объявляются через accessibility live region.

## Виджет

Виджет содержит имя владельца, входящий мем, статус и кнопку «Обновить». Изображение показывается целиком через `fitCenter`; при изменении пропорций виджета могут появляться поля. Ошибка сети не перекрывает последнюю загруженную картинку.
