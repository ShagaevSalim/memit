# Сервер Memit

Сервер принимает фотографии, обрезает их до квадрата, добавляет случайную надпись и фильтр, сохраняет JPEG и предоставляет последнее входящее фото для виджета.

## Требования

- JDK 21 или новее.
- Интернет при первом запуске Maven Wrapper.
- Доступный порт 8080.

## Запуск

Настройте `JAVA_HOME` на каталог JDK и выполните команды из каталога `backend`.

Windows PowerShell:

```powershell
.\mvnw.cmd spring-boot:run
```

Linux/macOS:

```sh
sh ./mvnw spring-boot:run
```

Дождитесь сообщения `Started MemitApplication`. Оставьте процесс запущенным, пока приложение и виджет используют сервер. Остановка: `Ctrl+C`.

Проверка доступности на компьютере сервера:

```powershell
curl.exe http://localhost:8080/api/health
```

Ожидаемый ответ: `{"status":"UP"}`.

## Подключение телефона по Wi-Fi

1. Подключите телефон и компьютер к одной сети.
2. Найдите локальный IP компьютера, например командой `ipconfig` в Windows.
3. Разрешите входящий TCP 8080 в брандмауэре для используемой частной сети.
4. Укажите в Memit `http://<IP-компьютера>:8080/` и проверьте подключение.

Гостевые Wi-Fi сети могут запрещать соединения между устройствами. Сервер слушает все сетевые интерфейсы; выключение компьютера или остановка процесса прерывает получение новых мемов.

## Подключение телефона по USB

Установите Android SDK Platform Tools, включите отладку по USB на телефоне и подтвердите разрешение подключения компьютера.

```powershell
adb devices
adb -d reverse tcp:8080 tcp:8080
```

В приложении укажите `http://127.0.0.1:8080/`. После переподключения USB повторите `reverse`. Общая Wi-Fi сеть для этого способа не нужна.

Если подключено несколько телефонов, используйте `adb -s SERIAL reverse tcp:8080 tcp:8080`, заменив `SERIAL` идентификатором из `adb devices`.

## Android Emulator

Если сервер работает на том же компьютере, укажите в приложении `http://10.0.2.2:8080/`. `localhost` внутри эмулятора относится к самому эмулятору.

## Данные и обработка фотографий

- `data/memit.mv.db` — база H2.
- `uploads/` — готовые JPEG.
- Аня (ID 1) и Максим (ID 2) создаются автоматически.

Запускайте сервер из каталога `backend`, чтобы расположение данных оставалось постоянным. Резервируйте базу и фотографии вместе.

Фотография обрезается по центру до квадрата без растяжения. Текст, его положение и фильтр выбираются при отправке и сохраняются в готовом JPEG; повторное скачивание не изменяет мем.

Для шрифта Impact поместите собственный лицензированный файл в `fonts/Impact.ttf`. Если файла нет, используется жирный SansSerif.

Демоверсия использует ID участников без авторизации. Она не предназначена для открытого размещения в интернете без дополнительной защиты. Контракт запросов: [API](../docs/API.md).
