# Тестирование Memit

## Автоматические проверки

Из каталога `android` с настроенными JDK 21 и Android SDK 35:

```powershell
.\gradlew.bat assembleDebug assembleRelease testDebugUnitTest lintDebug
```

Linux/macOS: `sh ./gradlew assembleDebug assembleRelease testDebugUnitTest lintDebug`.

Из каталога `backend`:

```powershell
.\mvnw.cmd test
```

Тесты Android проверяют multipart и ID участников, все восемь EXIF-ориентаций, обработку ошибок, блокировку повторной отправки, повтор после ошибки, сохранение настроек, кэш и состояния виджета. `DesignPreviewTest` создаёт рендеры XML в `android/app/build/reports/design/`.

## Сквозной тест с реальным сервером

Тест создаёт фотографии для обоих демопользователей. Используйте отдельный тестовый сервер.

В первом терминале из каталога `backend`:

```powershell
.\mvnw.cmd '-Dspring-boot.run.arguments=--server.port=18080 --spring.datasource.url=jdbc:h2:mem:android_e2e' spring-boot:run
```

Во втором терминале из каталога `android`:

```powershell
$env:MEMIT_TEST_BASE_URL = 'http://127.0.0.1:18080/'
.\gradlew.bat testDebugUnitTest --tests '*BackendIntegrationTest' --rerun-tasks
```

Без `MEMIT_TEST_BASE_URL` сквозной тест пропускается. Он нормализует JPEG с EXIF-поворотом, отправляет фото от Ани Максиму и обратно, проверяет latest и загрузку одинакового готового JPEG при повторном запросе.

## Проверка на двух устройствах

1. Запустите [сервер](../backend/README.md) и установите [debug APK](../android/README.md) на телефон и второе устройство.
2. На первом устройстве выберите Аню, на втором — Максима. Укажите адрес одного сервера с учётом способа подключения.
3. Разрешите камеру, сделайте снимок на устройстве Ани и отправьте его.
4. Добавьте виджет на устройстве Максима, нажмите «Обновить» и убедитесь, что пришёл новый мем.
5. Повторите отправку от Максима Ане.

Для проверки на одном телефоне отправьте снимок от Ани, затем смените пользователя на Максима и обновите виджет.

## Дополнительные сценарии

| Сценарий | Ожидаемое поведение |
|---|---|
| Первый отказ в разрешении камеры | Приложение остаётся открытым и позволяет повторить запрос |
| Постоянный отказ | Доступен переход к настройкам Android |
| Поворот устройства и смена камеры | JPEG отправляется с корректной ориентацией |
| Повторное нажатие во время отправки | Второй запрос не начинается |
| Ошибка отправки | Снимок остаётся для повторной попытки или пересъёмки |
| Нет входящих фото | Виджет показывает «Пока нет мемов» |
| Отключён сервер | Сохранённый мем остаётся видимым, можно повторить обновление |
| Смена владельца | Картинка предыдущего пользователя скрывается |
| Перезапуск приложения | Пользователь и адрес сервера сохраняются |
| Изменение размера виджета | Квадрат показывается целиком, надпись не обрезается |
| Закрытое приложение | Обновление виджета выполняется фоновой задачей |

Автоматические проверки не заменяют тестирование CameraX, системных разрешений и launcher на настоящем устройстве. Для Samsung, Xiaomi и Pixel следует проверить конкретные версии Android и рабочего стола.
